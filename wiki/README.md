# Home page

![](.gitbook/assets/meephawn.png)

Welcome to the wiki dedicated to Hawn. This plugin is still young, very immature, and still needs a lot of fine-tuning to be a good manager.

{% hint style="info" %}
To be able to navigate on the wiki, you have menus everywhere. For example if you are on a computer, you can see a large menu on the left side of your screen that shows you all the pages of the wiki.
{% endhint %}

### How do I download Hawn?

To get Hawn you have to go to the following web page: [https://www.spigotmc.org/resources/hawn-hub-lobby-management.66907/](https://www.spigotmc.org/resources/hawn-hub-lobby-management.66907/)

Accordingly, you will see a button "**Download Now**" on this page.

### What's the wiki for?

This wiki will show you the basics of the plugin and contains some explanations on features of the plugin. This wiki is still incomplete, and if you wish to see a page appear on the wiki, one that you don't see, notify me in the discord server.
