# Blacklist/Whitelist method (worldguard)

**WHITELIST**

* For example, if you put this method in the config file to ProtectionWorld.yml, in anti-place, you simply won't be able to place block on all regions listed in anti-place. **In short you can execute the event in the region, but not in the world.**

**BLACKLIST**

* For example, if you put this method in the config file to ProtectionWorld.yml, in anti-place, you simply won't be able to place block other than the listed regions, in fact it is the opposite of WHITELIST. **In short you can't execute the event in the region, but you can in the world.**
