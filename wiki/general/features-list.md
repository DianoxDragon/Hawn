# Features List

* **Set Spawn**
  * You can put multiple spawns, whatever the name, and the number. **It's unlimited.**
  * You can put a default spawn
  * With the creation of a spawn, you can see creation info of the spawn
  * You can put a spawn for new players
* **Server list**
  * You can put one free slot every time !
  * If the server is full, you can join it with a permission
  * You can put a simple motd
  * Fake max player
  * Can put a whitelist motd
  * Possibility to set random motd in the server list
* **On join**
  * You can teleport the player directly to the spawn (Custom spawn possible)
  * Vip custom spawn
  * You can set or no a motd
    * Per world possible
  * You can set a first join broadcast, and first join motd
  * Set join message or no, change it
  * Set custom join message per group and, or per world
  * Can put a silent join
  * Set the gamemode
  * Can restore food and health
  * Custom sound on spawn (per world too)
  * Custom Firework on spawn
    * For first join only or not
  * Lightning strike effect
  * forcefully select a slot from the player's inventory when he connects.
  * Clear inventory and clear chat
  * Set custom xp (level and exp)
  * Execute commands
    * If the player is new or not
    * By the console or not
  * Set fly on join
  * **Title on join**
  * **Actionbar on join**
    * Work with ticks (20 ticks = 1 second)
  * Speed on join
  * You can put potion effects on join :
    * **BLINDNESS** effect
    * **JUMP** effect
  * First join, or/and on join boss bar (doesn't work 1.8)
    * Manage color, progress, and style
* **Custom Join Item**
  * You add one special item, the item is to **hide or show** the players, but it's customizable, of course.
  * Create a custom custom join items, with name and lore, and the command list works like the custom command module, so no limits about commands
  * When you die, you can get the items
  * Special item - Lobby bow
  * Special item - Fun gun
  * You can create your own custom books
  * Works per world
* **On quit**
  * Set quit message or no, change it
  * Set custom on quit message per group and, or per world
  * Can put a silent quit
  * Execute commands
* **Events**
  * VoidTP
    * Custom spawn
    * Custom sound
    * Custom firework
    * VoidTP per world also
      * Disable the void Tp (imagine you have a skyblock, put a command for the tp to his/her island)
      * Custom command per world
    * You can execute commands
      * You can execute commands with players, console, with permissions, and classic messages
  * Can keep the player's gamemode and food level
  * Anti-Damage for the player
    * Worldguard Support
  * You can put colors on signs with **&**, and emojis too
  * Anti Drop Items, Anti PickUp Items, Anti Move items, Anti Damage items (in the inventory) for players
    * For anti drop, pickup and move item, there are a worldguard support
  * Anti item/block interaction
    * That disable the interaction of **ACACIA\_DOOR**, **ACACIA\_FENCE\_GATE**, **BIRCH\_DOOR**, **BIRCH\_FENCE\_GATE**, **CHEST**, **DARK\_OAK\_DOOR**, **DARK\_OAK\_FENCE\_GATE**, **OAK\_FENCE\_GATE**, **JUNGLE\_DOOR**, **JUNGLE\_FENCE\_GATE**, **CHEST\_MINECART**, **OAK\_DOOR**, **OAK\_TRAPDOOR**, **TRAPPED\_CHEST**, **OAK\_DOOR, ANVIL, BEACON, RED\_BED, OAK\_BOAT, BREWING\_STAND, COMMAND\_BLOCK, DAYLIGHT\_DETECTOR, DISPENSER, DROPPER, ENCHANTING\_TABLE, ENDER\_CHEST, FURNACE, HOPPER, HOPPER\_MINECART, LEVER, MINECART, NOTE\_BLOCK, COMPARATOR, OAK\_SIGN, SPRUCE\_DOOR, SPRUCE\_FENCE\_GATE, SPRUCE\_TRAPDOOR, BIRCH\_TRAPDOOR, JUNGLE\_TRAPDOOR, ACACIA\_TRAPDOOR, DARK\_OAK\_TRAPDOOR, SWEET\_BERRY\_BUSH**
    * You can disable a block, if you don't want the protection for one block for example and more
  * Disable death messages
  * Instant respawn (with delay, and more)
  * Clear drop on death
  * JumpPad // LaunchPad
    * With cooldown
    * With messages//sounds
  * DoubleJump
  * When a world change occurs:
    * Possibility to disable or enable fly
      * Not work if double jump is enable
    * Possibility to change a gamemode state
    * Change player options
  * Always Day and Always Night in the world you want
    * Just keep the day or the night, it doesn't block the time
  * Possibility to execute a command when a player change world
  * Effects (generally for fun):
    * Put diamond boots when flying (option)
  * Block the off hand (second hand and - Doesn't work if spigot or a fork of spigot is in 1.9)
  * Block the usage of the shear (like on a sheep)
  * Can disable the player mount/ride event
  * Sign system
    * Can create all events you want on a sign
* **Chat**
  * You can put color in the chat
    * Per group or per color !
  * Emojis are available
    * Every emojis are customizable per permission
    * Enable or not every emojis
    * Possibility to add aliases
    * Unlimited amount of emojis
  * Anti-Swear
    * Can notify staff
    * Unlimited words to replace or not
  * AutoBroadcast
    * Random messages or not
    * Custom interval (in ticks)
    * Support centered messages, permission
    * Json and placeholderapi work of course
    * per world
    * Unlimited messages with colors
    * Custom header and footer
    * For classic autobroadcast, you can autocenter all messages
    * For classic autobroadcast, you can set the message for a, or many worlds
    * For classic autobroadcast, you can set some events
      * To play a sound to the player
        * **\[sounds]: sound name**
        * To send a sound with a message in the autobroadcast put a new line message '**\[sounds]: \<sound>**' like custom command
    * **Also, separated autobroadcast for titles, for bossbar and actionbar (if you want)**
    * You can disable the autobroadcast visibility with a command - **/option autobc**
  * Mentions
    * **TabComplete** working with **@** - only **1.8-1.12**
    * To **mention a player** you need to write in the chat **@ + the name of the player** like [@DianoxDragon](https://www.spigotmc.org/members/624284/)
    * **Chat highlight mention**
    * **The possibility** (config) **to mention him/herself** or **no**
* **Tablist**
  * Create footer and header
    * Support placeholders and colors
    * Support placeholderapi and hawn placeholders
  * FULLY animated (with variable and more, see help for more)
* **Scoreboards**
  * Create unlimited scoreboards
  * One scoreboard, one permission
  * It's animated, with the text or the title (Scroller too) !
  * You can put as many world supported as you want per scoreboard
  * Support PlaceHolderAPI
  * Lagless
  * Anti-Flicker
* **Protections/Worlds**
  * Anti-Breaks & Anti-Place for blocks
    * Worldguard Support
    * Add blocks exception, that people can use without restriction (you can block or allow blocks, works like the worldguard method in the hawn configuration files)
  * PlayerInteractEntity-ItemFrame & HagingBreakByEntity protection
    * Worldguard Support
  * Disable Weather, lightning strike, and thunder change
  * Anti block burn, Anti explosion, Anti fire spread
    * Worldguard support
  * Anti Leaf decay, anti block fade (with farm protect)
  * Anti mob/animals spawning
  * Anti lava and water bucket use
  * Anti world downloader (block most of the cases)
  * You can prevent mobs from using portals
* **Commands**
  * Command **/help** (and **/?**) to customize your help pages
    * Unlimited pages, text, categories
    * Customize like you want as usual
  * Can block commands
    * Play a sound and an animation for the one who try to execute a blocked command (only 1.13 and 1.14)
    * Can notify the staff
  * Manage your chat:
    * Command **/cc** to clear the chat
      * Customize like you want as usual
    * You can mute the chat /globalmute
    * You can put a **delay** on your **chat**
  * You can see your ping or a player's ping
  * You can see the tps of the server too
  * Broadcast msg, title, action bar
    * Multi-line support for /broadcast
      * When you put **//n** in the message, a new line will be created
    * Broadcast - Custom default prefix, default chat color, and a sound is played to everyone if you want
    * Title announces are customizable
      * With firework
      * Sound
      * and possibility to send what you wrote in the chat
  * Manage the weather and the time
  * Heal player
  * Feed player
  * Manage warps
  * /warp and /spawn delay possible (with cancel events too)
  * Can create custom commands:
    * You can create as much as command as you want
    * For the moment it's only info commands, like create a /discord, or a /twitter
    * Of course, subcommands can work, /discord help, or /discord ip for exemple can work, you need to create them like a real command
    * Support centered messages, permission per line, world per line
    * Can set a cooldown for each commands
    * You can put as many messages as you want, with json and placeholderapi of course
    * You can put **custom event**
      * To execute a commande by a player in custom command
        * **\[command-player]**: the command without /
      * To execute a commande by the console in custom command
        * **\[command-console]**: the command without /
      * To put a custom gamemode for a player, you need to put only that on a line
        * **\[gamemode-survival]**
        * **\[gamemode-creative]**
        * **\[gamemode-adventure]**
        * **\[gamemode-spectator]**
      * To show the ping for a player, you need to put only that on a line
        * **\[ping]**
      * To send title
        * **\[send-title]:** \<your message with //n if you want to>
        * **\[send-title\[\<number>]]:** \<message>
          * Work with ticks (20 ticks = 1 second)
      * To send Action bar
        * **\[send-actionbar]:** \<message>
        * **\[send-actionbar\[\<number>]]:** \<message>
          * Work with ticks (20 ticks = 1 second)
      * To tp directly to a spawn
        * **\[spawn]: \<spawn name>**
      * To tp directly to a warp
        * **\[warp]: \<warp name>**
      * To tp to a server linked with bungeecord
        * **\[bungee]: \<server name>**
      * Play a sound to the player
        * **\[sounds]:** sound name
      * To put a potion effect
        * **\[effect\[**\<Amplifier in number>**]]:** \<potion name>
      * To remove a potion effect
        * **\[effectclear]:** \<potion name>
      * To clear all potions effect
        * **\[effectclearall]**
      * To execute a custom command
        * **\[customcommand-player]:** the custom command you created
      * To send a custom firework:
        * **\[FWLU]:** the name of the firework in Firework-List.yml
  * Vanish command
    * With the possibility to know if we are vanished or not (action bar)
  * Clear inventory
  * Emojis list gui
    * To see every emojis usable
  * Admin panel :
    * You can enable or disable many parts in the plugin configuration files. Directly from a GUI, with a simple click, and it takes effect immediately.
  * Toggle on or off the scoreboard
  * Player option :
    * Manage speed (also flyspeed) and the player visibility
    * Manage player visibility
    * Manage Jumboost
    * Manage fly and doublejump
    * Manage auto broadcast visibility
    * Works per world ! too
  * YOU can disable the load of ANY commands of the plugin (except /hawn and /adminpanel)
  * Change your scoreboard with a command
  * Warning command
  * Gamemode command
    * Quick gamemode (option)
    * And can put the hawn build mode (option)
  * See the list of spawns
  * Go the highest block of your location
  * **/hawn urgent** that put the lobby in emergency situation
    * CREATE A COPY OF THE SERVER
    * Log if a file of hawn has been changed with the admin panel
    * Disable the access of the lobby of normal players
    * Can only be disabled by the console
    * Disable all plugin functions (customizable)
    * You can execute it only on the console if you want
  * Repair items
  * See player inventories
  * See the enderchest of players
  * Kill yourself
  * Getpos
  * Get the ip
  * Put a hat
  * kickall
  * Clear all items on the ground (for all worlds)
  * Clear all mobs (for all worlds)
  * Parse Hawn placeholders
  * Check player accounts (options)
  * Exp manage command
  * Player list command (message and gui)
  * No clip
  * Give nightvision
  * Some worldedit shortcut
  * Can edit some players directly with a gui
  * Workbench player
  * Burn player
  * Skull player
* **World system**
  * You can manage your worlds with hawn
    * Create, Delete, Import, List, Tp, Info, Unload
  * Gui system
  * Can manage 70 worlds for now
* **FULLY (really) Customizable**
  * Almost, everything is customizable
  * Good compatibility with materials and sounds (regardless of the version of the game)
  * Add FULLY registered command aliases manually
  * Create a lot of fireworks, and use it for custom commands and more
  * **Customizable messages (even the /help)**
    * You can set or no some messages, with multiples lines
    * You have a couple of variables already available, even a %prefix% customizable
    * And sometimes you can see wich permission you need for a command and more
    * Put title or/and actionbar !
    * In short, it works like custom command, but for messages ! Just add a custom event between theses events (works also with join and quit commands):
      * To send title
        * **\[send-title]:** \<your message with //n if you want to>
        * **\[send-title\[\<number>]]:** \<message>
          * Work with ticks (20 ticks = 1 second)
      * To send Action bar
        * **\[send-actionbar]:** \<message>
        * **\[send-actionbar\[\<number>]]:** \<message>
          * Work with ticks (20 ticks = 1 second)
    * Support centered messages
      * Add **<--center-->** only after **\<perm>//\</perm>** if you put it
    * You can **set permission for a message** (what line you want)
      * \- '**\<perm>permission\</perm>** **msg**'
        * It must be placed at the very beginning of the line, as the example shows
    * You can **set a world only for a message or a command** (what line you want)
      * \- '**\<world>world\</world**> **msg**'
        * It must be placed at the very beginning of the line AND before **\<perm>perm\</perm>**
    * **Json** supported
    * Language type supported, and you can create your own message folder
      * **en\_Us**, **fr\_FR** are implemented by default
      * You are free to help me to translate the plugin into another languages
    * **PlaceholderAPI** supported
    * **MVdW placeholders** supported
    * Custom placeholder supported
      * **BattleLevels** supported
  * **Customizable per world**
    * You can customize the motd per world
    * All the protections per world
    * Events per world
    * and more
  * **WorldGuard supported**
    * **Worldguard 6.1+ is supported, not older**
      * The plugin will automatically detect if you use worldguard 6 or 7, for compatibility reason
* **Others**
  * The plugin can check if it is up to date or not
  * Store players informations (Mysql or not) - (very needed informations for future of hawn) :
    * Player name, uuid, ip, join date, first join date
    * Player last location deconnection and gamemode
    * Use ssl or not
  * Between lobbies (Mysql)
    * You can be tp to your last position
    * You can keep your last gamemode state
    * Keep your vanish state mode
    * (automatically) keep your speed option
    * Keep your option of jumpboost
    * Keep your option of player visibility
    * Keep your scoreboard
    * Keep your fly/doublejump
    * Keep your option for autobroadcast visibility
  * Choose between 12 hours or 24 hours time
  * Save the number of connections per players
